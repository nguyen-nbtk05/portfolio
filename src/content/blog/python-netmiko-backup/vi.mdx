# Tự động sao lưu cấu hình bằng Python và Netmiko

> **Nội dung mẫu:** Đây là dữ liệu minh họa để kiểm thử blog portfolio. Hãy thay bằng hướng dẫn đã được rà soát trước khi áp dụng cho mạng thật.

Một bản sao lưu cấu hình chỉ thực sự hữu ích khi quy trình **lặp lại được, dễ tìm kiếm và dễ khôi phục**. Mô hình lab nhỏ này kết nối tới danh sách thiết bị đã biết, lấy cấu hình đang chạy và lưu một bản có dấu thời gian mà không thay đổi thiết bị.

## Phạm vi của bài lab

- Đọc thông tin thiết bị từ một inventory đơn giản.
- Kết nối SSH bằng `Netmiko`.
- Lưu một tệp UTF-8 riêng cho từng thiết bị.
- Ghi nhận lỗi mà không dừng toàn bộ tác vụ.
- So sánh các bản sao lưu để phát hiện sai lệch cấu hình.

Ví dụ chỉ lấy thông tin xác thực từ biến môi trường. Khi triển khai thật, hãy dùng hệ thống quản lý bí mật và tài khoản tự động hóa chỉ có quyền đọc.

## Inventory mẫu

| Tên | Nền tảng | IP quản trị | Lệnh |
| --- | --- | --- | --- |
| branch-rtr-01 | Cisco IOS | `10.20.0.11` | `show running-config` |
| branch-sw-01 | Cisco IOS | `10.20.0.21` | `show running-config` |
| edge-fw-01 | Linux lab | `10.20.0.31` | `show configuration` |

Bạn có thể lưu inventory trong hệ thống quản lý phiên bản, nhưng không bao giờ commit mật khẩu hoặc khóa riêng. [Tài liệu Netmiko](https://ktbyers.github.io/netmiko/) liệt kê các giá trị `device_type` được hỗ trợ và hành vi riêng của từng nền tảng.

## Script sao lưu tối giản

```python
from datetime import datetime, timezone
from pathlib import Path
import os

from netmiko import ConnectHandler

devices = [
    {
        "name": "branch-rtr-01",
        "device_type": "cisco_ios",
        "host": "10.20.0.11",
    },
    {
        "name": "branch-sw-01",
        "device_type": "cisco_ios",
        "host": "10.20.0.21",
    },
]

output_dir = Path("backups")
output_dir.mkdir(exist_ok=True)
stamp = datetime.now(timezone.utc).strftime("%Y%m%dT%H%M%SZ")

for device in devices:
    connection = ConnectHandler(
        **device,
        username=os.environ["NET_USERNAME"],
        password=os.environ["NET_PASSWORD"],
    )
    try:
        config = connection.send_command("show running-config")
        destination = output_dir / f"{device['name']}-{stamp}.cfg"
        destination.write_text(config + "\n", encoding="utf-8")
        print(f"saved {destination}")
    finally:
        connection.disconnect()
```

Chỉ chạy script từ máy đã được phép truy cập mạng quản trị:

```bash
python -m venv .venv
python -m pip install netmiko
python backup_configs.py
```

## Làm cho lỗi dễ quan sát

Một tác vụ theo lịch nên trả về mã thoát khác không khi bất kỳ thiết bị nào gặp lỗi. Log cần có tên thiết bị, nhóm lỗi và dấu thời gian nhưng tuyệt đối không chứa bí mật. Một số nhóm lỗi hữu ích gồm:

1. Lỗi DNS hoặc kết nối TCP.
2. Xác thực thất bại.
3. Lệnh bị quá thời gian chờ.
4. Kết quả rỗng hoặc ngắn bất thường.
5. Không thể ghi vào hệ thống tệp hoặc repository.

Để phát hiện drift, hãy chuẩn hóa các dòng thường xuyên thay đổi như dấu thời gian trước khi tính hash hoặc diff. Checksum thay đổi là tín hiệu cần xem xét, không tự động chứng minh đã xảy ra sự cố.

```text
branch-rtr-01  OK      14.821 byte  có thay đổi
branch-sw-01   OK      11.403 byte  không đổi
edge-fw-01     FAILED  xác thực
```
